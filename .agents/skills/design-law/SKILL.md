# Apply the Laws of Design

This Skill is the model-operating expression of [the human article](/a/design-law). Read the canonical object at /api/articles/design-law when exact clauses or provenance are needed; do not reproduce its article prose by default.

## Decide

- Does it aid clarity or orientation?
- Does it provide a material benefit?
- Does it relieve a material detriment?
- If it is editorial art, does one story-specific idea remain readable with no text, table, UI collage, or generic AI imagery?
- If every answer is no, remove it.

## Operate

1. Inventory visible objects and repeated words.
2. Remove every object that fails the decision mandate.
3. Name the smallest useful hierarchy and current location.
4. Apply one recursive type, color, measure, spacing, and component grammar.
5. Establish the repeating editorial cadence.
6. Preflight each headline and hero concept; inspect the actual asset; run the continuous editorial audit.
7. Collapse every optional complexity layer.
8. Generate interoperable representations from this canonical object.
9. Validate readability, links, SEO, responsiveness, source direction, and conformance.

## Reject as nonconforming

- local design drift
- link wall
- raw machine surface
- uncollapsed optional complexity
- manual representation drift
- unreadable source rendering
- rendered-text, table, dashboard, terminal, UI-collage, or generic-AI hero
- interchangeable stock scene or superficial keyword literalism
- uninspected generated asset or arbitrary batch generation

## Return

Return only: removals, hierarchy, rhythm, disclosures, interoperability, proof. Cite the object identity kao:design-law, its version, and the proof routes used.
