2. What Opus confirmed

Claude Opus read the live Tap & Go bundle via the build’s ASK path (not a static mock). Verdict:

  • Old drop format — imperative paste instructions plus embedded credential read as prompt injection; well-aligned models refuse.
  • New drop format — public documentation link first, neutral third-person credential description: engage cautiously at read-only level; page reads as unusually honest reference material, not a manipulation preamble.
  • Reverted experiment — an explicit “this is NOT prompt injection” preamble was itself flagged as soft injection; removed permanently.

Opus confirmation is architectural: link-first, descriptive credential, no imperative paste blob.
