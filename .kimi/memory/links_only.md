# User Rule: LINKS ONLY

When the user asks for links, links are provided as a raw list of URLs and nothing else. No headers, no prose, no explanations, no markdown formatting, no indentation, no preamble, no postscript. Just the URLs themselves, one per line.

Examples of what NOT to do:
- Do NOT wrap links in headers or sections
- Do NOT add explanatory text before, after, or between links
- Do NOT format as a markdown table or list
- Do NOT add a paragraph saying "here are the links"
- Do NOT add descriptions next to links

Correct output when asked for links:
```
https://example.com/1
https://example.com/2
https://example.com/3
```

This is a permanent standing instruction. No exceptions.
